## How to search by parameter count

For example, on Hugging Face:

1. Open [Hugging Face Models](https://huggingface.co/models?pipeline_tag=text-generation&utm_source=chatgpt.com).
    
2. Select Parameters in the filters.
    
3. Enter your desired range, such as 0–7 billion.
    
4. Filter by Text Generation, Image-to-Text, or other capabilities.
    
5. Sort results by trending, downloads, or likes.
    

One important distinction: A 3B model can outperform a 7B model on certain tasks. Parameter count measures model size, not necessarily intelligence. Also, mixture-of-experts models can have different total and active parameter counts.

My recommendation: Start with Hugging Face for the largest selection, or LockML if you want a simple maximum-parameter filter combined with capability comparisons.
