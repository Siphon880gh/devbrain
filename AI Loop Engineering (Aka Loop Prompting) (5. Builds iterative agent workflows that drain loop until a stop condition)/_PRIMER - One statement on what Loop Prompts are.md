Loop Prompting is building an iterative agent workflows that drain loop until a stop condition

**Iterative agent workflows** means the AI repeatedly works through a cycle:
1. Takes an action
2. Checks the result
3. Decides what to do next
4. Repeats until the task is complete

For example:
> Write code → run tests → find errors → fix code → rerun tests

Simpler wording:
> **Loop prompting: Makes an AI repeatedly act, check, and improve until it reaches a goal or stopping point.**
