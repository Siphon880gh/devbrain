## Three Integration Modes

1. **iframe embed** — [authoring tool](https://timeline.knightlab.com/#make) + Google Sheet URL
2. **Google Sheet** — same data source; sheet edits update live timeline
3. **JSON + `TL.Timeline`** — full control, private data, custom UI

CMS plugins: WordPress, MediaWiki, Drupal.
