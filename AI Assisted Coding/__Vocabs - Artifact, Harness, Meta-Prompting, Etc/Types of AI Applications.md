**AI-native app**  
Software whose central experience depends on AI. Removing the AI would fundamentally change or eliminate the product’s primary value.

**Agentic app**  
An application containing an AI agent that can plan, use tools, make decisions, and complete multi-step tasks—not merely generate content.

**Agent-first app**  
An app designed so anything a user can do through the interface can also be done by an agent. The UI and agent operate on the same persistent, synchronized state.

**Agent-native app**  
An app in which agents are part of the core architecture rather than an AI feature added later. Its interface, actions, tools, and data model are designed from the beginning for both people and agents.
