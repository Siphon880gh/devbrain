

**Harness**  
The environment surrounding an AI model that gives it access to tools, files, instructions, memory, and code execution. Cursor, Codex, and Claude Code are examples of coding harnesses.

**Harness-first app**
An emerging, nonstandard term for an app primarily created, configured, or controlled through an AI coding harness such as Cursor. Most interactions with the app’s data layer—such as generating, enriching, editing, or deleting information—happen through prompts or direct file manipulation in the harness. The app primarily provides a more readable, structured, and visually useful way to explore the data when artifacts inside the harness’s chat interface are insufficient. It may still support direct user interactions, but these often save requests for the AI to process later through the coding harness (for example, PUTTING into a json file for the coding harness to read).

**Meta-prompting**  
Using AI to create, evaluate, or improve prompts that will guide another AI process.

**Prompt handoff**  
A workflow in which one app prepares a prompt for the user to copy into an external AI harness. After the harness completes the work, the user returns to the app to view or continue working with the result.

**Vibe coding**  
Building software mainly by describing the desired result to an AI coding tool and iteratively refining what it produces, without manually writing or reviewing every line of code.
