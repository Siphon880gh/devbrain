Handing work from one AI platform to another makes it possible to continue the same project without starting over.

Common reasons to switch platforms include:

- You have run out of tokens, credits, or usage capacity on the platform you are currently using.
- You do not like the platform's generations and want to try the same task with another AI.
- Another platform may be better suited to the next part of the task or offer tools that the current platform does not.

The progress made so far can still be preserved. When both platforms can access the same local project files, the code and saved edits are already available to the receiving platform. See [[Handoff Between Codex CLI and Cursor on Local Files]] for an example.

Chat history usually does not transfer automatically, so give the receiving AI a short status update explaining what was completed, what remains, and which files or constraints matter.
