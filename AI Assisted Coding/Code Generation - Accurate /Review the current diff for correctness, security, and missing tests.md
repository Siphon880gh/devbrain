When you want a review of what is already changed, not a new implementation:

```
Review the current diff for correctness, security, and missing tests.
```

With Codex CLI, pair this with the read-only shortcut so the review cannot edit files:

```
cxr "review this diff for bugs and regressions"
```

See [[Codex CLI - Shell shortcuts cx, cxr, cxw]].
