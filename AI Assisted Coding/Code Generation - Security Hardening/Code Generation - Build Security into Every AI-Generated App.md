## Build Security into Every AI-Generated App

For every new app generated with AI, include the [[Enterprise - SECURITY, Code Standards, Compliance/_Standards/Prompt Partial - Secure App Build|Secure App Build prompt partial]] with the product requirements, before implementation begins.

Use it as a default requirement, not as a final audit after the app has already been generated. Adapt stack-specific details where necessary, but do not silently omit a requirement. Have the AI map each security requirement to its implementation and automated tests, and explicitly flag anything it cannot complete.

For the longer review and release baseline, use [[Enterprise - SECURITY, Code Standards, Compliance/_Standards/Security - App Build Checklist|Security - App Build Checklist]].
