## Claude Code Variants

| Claude Code version                  | API key required?    | Uses                                |
| ------------------------------------ | -------------------- | ----------------------------------- |
| **CLI**                              | **No**               | Claude subscription via login/OAuth |
| **Desktop app**                      | **No**               | Claude subscription/OAuth           |
| **Claude Code Web**                  | **No**               | Claude subscription                 |
| **CLI with `ANTHROPIC_API_KEY` set** | **Yes, effectively** | **Pay-as-you-go API billing**       |

Basically Claude Code CLI allows you to use either subscription or pay-as-you-go API tokens
