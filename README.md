## Can I master or learn everything from these notes

I have over 4,000 notes on programming and AI. Some are sequential lessons. Some are reference notes. Some are self-contained lessons. There is no table of contents that walks you through the whole set. These notes were written for my own work, not as a paid course, so I did not build a guided path through every file.

You can learn a skill from a sequential folder (AWS curriculum, React Native leveling, a prompt-engineering library, a Next.js + Supabase path). You cannot treat this vault as a complete computer-science degree or a single ordered map of “all programming and AI.” Most folders are a mix of primers, look-ups, and one-off lessons. A short map of the leveling paths that do exist is in `Z - Learn by leveling up MOC (Devbrain).md`.

## What you can learn

### AI work, by role
1. **Prompt engineering** — prompt fundamentals, libraries, image and video generation, and platform notes (ChatGPT, Google AI, NotebookLM, Higgsfield, Midjourney).
2. **AI API developer** — calling AI services, chat bots, LangChain, OpenAI platform details, and frontend query nuances.
3. **AI engineer** — concepts, practice exercises, turning papers into tools, local LLM runtimes (Ollama, LM Studio, Hugging Face, Colab), and node-based tools (ComfyUI, Langflow, n8n).
4. **Agentic engineer** — orchestrated agents, Autogen, hardware planning, and related agent notes.
5. **Loop engineering** — iterative agent workflows that run until a stop condition.
6. **Graph engineering** — connected, multi-path reasoning networks.

**AI-assisted coding** sits beside those roles: Cursor, Claude Code, Codex, Copilot, harness-first and agent-first app notes, design generation (including 3D web), Git with AI, and security / governance around generated code.

### Web development
Frontend (JavaScript, HTML, CSS, React, TypeScript, Tailwind, older jQuery stacks), backend and SSR (PHP, Python, Node, Next.js, GraphQL), shared full-stack topics (regex, dates, encryption), package managers, no-code / low-code (WordPress, Webflow, Framer), and planning in Figma.

### Cloud, data, and enterprise
AWS curriculum plus Azure and Google Cloud. Databases (MySQL, PostgreSQL, Mongo, Prisma, ORMs). Data engineering, statistics, and cloud analytics. DevOps (Docker, Kubernetes, CI/CD, Redis, scaling). Linux and server administration. Firebase, Supabase, Vercel, Netlify, Heroku. Testing, security, compliance, email, caching, Stripe, and support-docs / chatbot notes for shipping a product.

### Computer science and languages
Systems design, data structures, algorithms, design patterns, clean code, and logic. General-purpose C, C++, and Java. Console apps. Culture and vocabulary across languages and tools.

### Platforms and tools
Git / GitHub / GitLab. Chrome extensions. React Native. iOS and Android. Windows software. Developer tools (VS Code, Vim, Chrome DevTools, Postman). Scraping libraries and APIs. Plugin and software-suite development (including HubSpot and Notion APIs).
