## Local skills

When asked about local skills, or what AI can do at this vault or knowledge base:

1. List `.agents/skills/` at query time. Do not hardcode the skill list.
2. Read each skill's `SKILL.md` (name, description, and when to use it).
3. Answer from that live folder so new or removed skills are reflected automatically.
4. If a listed skill matches the current task, follow that `SKILL.md`.
